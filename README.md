# Bot-discord-perron

Revisa el archivo "config.json" para que sepas que cosas tienes que añadir.

La variable "token" sirve para que el bot funciona, averigua donde conseguir el token en la pagina "discord developer".

La variable "Channel" es para que especifiques en que canal quieres que se ejecute el bot (Aclaracion: con el comando /ip no funciona lo del canal).

La variable "IP" es para que especifiques la ip del servidor de minecraft.
